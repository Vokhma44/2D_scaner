# netscan — телефон вместо USB-сканера 2D

> Мобильный декодер принимает только двумерные форматы (DataMatrix, QR,
> PDF417 и Aztec). Это исключает ложное распознавание фрагментов DataMatrix как
> короткого линейного EAN-8; при нескольких кодах приоритет получает DataMatrix.

Мобильное приложение и агент для ПК, которые вместе заменяют настольный сканер
штрихкодов. Телефон снимает код камерой и по локальной сети отдаёт его на
компьютер, а агент вводит код в **активное окно** — так же, как это делает
USB-сканер в режиме HID keyboard wedge. Учётная система (1С, WMS, CRM, любая
форма в браузере) ничего не знает о телефоне: для неё это обычная клавиатура.

```
 ┌──────────────┐   Wi-Fi / LAN, HTTPS + WebSocket   ┌──────────────────────┐
 │   телефон    │ ─────────────────────────────────▶ │   агент на ПК        │
 │  PWA-сканер  │  {"type":"scan","code":"0104..."}  │  эмуляция клавиатуры │
 │  камера, QR  │ ◀───────────────────────────────── │  буфер, файл, вебхук │
 └──────────────┘        {"type":"ack",...}          └──────────┬───────────┘
                                                                │ ввод в активное окно
                                                     ┌──────────▼───────────┐
                                                     │  1С / WMS / браузер  │
                                                     └──────────────────────┘
```

Приложения устанавливать не нужно: мобильный клиент — это PWA, которую раздаёт
сам агент. Телефон открывает страницу по QR-коду с экрана ПК и при желании
добавляет её на домашний экран.

В готовой Windows-сборке агент работает в системном трее без постоянно
открытого окна командной строки. Двойной щелчок по значку РУЗНАК открывает
консоль управления; через контекстное меню можно показать QR-код или завершить
работу агента.

## Быстрый старт

```bash
./gradlew :agent:installDist          # соберёт агент и мобильный клиент
agent/build/install/netscan/bin/netscan
```

В консоли появится QR-код. Наведите на него камеру телефона — браузер откроет
сканер, сопряжение произойдёт само. Дальше наводите телефон на товар: код
появится там, где стоит курсор на ПК.

Полезные ключи запуска:

```bash
netscan --suffix tab            # после кода нажимать Tab, а не Enter
netscan --typing clipboard      # вводить через буфер обмена (см. «Раскладка»)
netscan --sink console,file --file ~/scans.txt
netscan --webhook http://localhost:3000/scan
netscan --port 9443 --approve-devices
netscan --help
```

## Что умеет

**На телефоне**

- QR, DataMatrix, PDF417, Aztec, Code 128/39/93, EAN-13/8, ITF, UPC — то есть
  весь набор, ради которого покупают 2D-сканер;
- распознавание встроенным в браузер `BarcodeDetector` (Chrome на Android), с
  автоматическим переходом на ZXing там, где его нет (Safari на iOS);
- непрерывный режим и режим «по одному коду», звук и вибрация при считывании;
- фонарик, приближение, выбор объектива, настраиваемая область поиска;
- экран не гаснет во время работы;
- **офлайн-очередь**: коды, отсканированные вне зоны Wi-Fi, дожидаются связи и
  уходят на ПК автоматически, без дублей;
- ручной ввод кода, журнал последних сканов с состоянием каждого;
- установка на домашний экран, работа в полноэкранном режиме.

**На ПК**

- ввод в активное окно эмуляцией клавиатуры; альтернативы — буфер обмена,
  консоль, файл, HTTP-вебхук (можно включить сразу несколько);
- префикс, суффикс (`Enter`, `Tab`, `Tab+Enter`, ничего), задержка между
  символами, пауза перед вводом — привычные настройки сканера;
- обработка разделителя GS1 (ASCII 29) в кодах маркировки;
- подавление повторов, фильтры по длине, символике и регулярному выражению;
- несколько телефонов на один ПК, ввод не перемешивается;
- веб-консоль на `https://localhost:8443/console`: QR, устройства, журнал
  сканов, все настройки и кнопка проверки ввода.

## Как это устроено

| Каталог | Что внутри |
| --- | --- |
| `agent/` | агент для ПК: Kotlin, Ktor, WebSocket, эмуляция клавиатуры |
| `agent/src/main/resources/console/` | веб-консоль оператора на ПК |
| `mobile/` | мобильный клиент: TypeScript, Vite, PWA |
| `docs/` | протокол, безопасность, установка |

Сборка мобильного клиента встроена в Gradle: `:agent:processResources` вызывает
`npm ci && npm run build`, а Vite кладёт результат в ресурсы агента. Если Node.js
на машине нет, а ресурсы уже собраны, сборку клиента можно пропустить:

```bash
./gradlew build -PskipWeb=true
```

### Почему HTTPS обязателен

Браузер даёт доступ к камере только в защищённом контексте. Публичный
сертификат для адреса вида `192.168.1.10` получить негде, поэтому агент при
первом запуске выпускает собственный сертификат с адресами всех сетевых
интерфейсов ПК и хранит его в `~/.netscan/keystore.p12`. При смене сети
сертификат перевыпускается автоматически.

Телефон один раз покажет предупреждение о неизвестном издателе — это ожидаемо.
Отпечаток сертификата печатается при старте агента, его можно сверить.
Подробности и способ убрать предупреждение — в [docs/SECURITY.md](docs/SECURITY.md).

### Раскладка клавиатуры

Эмуляция клавиатуры работает поверх раскладки, активной в ОС, — ровно как у
настоящего USB-сканера. Если на ПК включена русская раскладка, латинские буквы
кода превратятся в кириллицу. Варианты:

- `--typing clipboard` (по умолчанию) — код вставляется через буфер обмена, раскладка не важна
  (прежнее содержимое буфера агент возвращает на место);
- `--typing hybrid` — латиница и цифры набираются клавишами,
  остальные символы вставляются через буфер;
- `--typing keys` — только нажатия, максимально близко к USB-сканеру.

Цифры от раскладки не зависят, поэтому для чисто цифровых кодов подходит любой
режим.

## Настройки

Все настройки хранятся в `~/.netscan/config.json`, правятся из веб-консоли и
перекрываются ключами командной строки. Ключи запуска записываются в файл, то
есть скрипт запуска настраивает агент один раз.

| Раздел | Ключевые параметры |
| --- | --- |
| `network` | `httpsPort`, `httpPort`, `bindAddress`, `advertisedHost` |
| `security` | `requireDeviceApproval`, `pairingTokenTtlMinutes`, `pairingAttemptsPerMinute` |
| `scan` | `duplicateWindowMs`, `allowedFormats`, `minLength`, `maxLength`, `filterRegex` |
| `output` | `sinks`, `prefix`, `suffix`, `typingMode`, `keyDelayMs`, `gs1SeparatorReplacement`, `filePath`, `webhookUrl` |

## Разработка

```bash
./gradlew :agent:test            # тесты агента
./gradlew :agent:installDist     # сборка агента вместе с PWA
cd mobile && npm run dev         # мобильный клиент с горячей перезагрузкой
python3 mobile/tools/generate-icons.py   # перегенерация иконок PWA
```

Рабочее состояние агента (`~/.netscan/`): `config.json`, `devices.json`,
`pairing.txt`, `keystore.p12`. Удаление каталога полностью сбрасывает
настройки и сопряжения; `netscan --reset-pairing` отзывает устройства и
выпускает новый код.

## Ограничения

- Ввод в активное окно на Linux работает в сессии X11; в Wayland системный
  протокол не разрешает синтетические нажатия — используйте приёмники
  `clipboard`, `file` или `webhook`, либо сессию X11.
- На macOS для эмуляции клавиатуры нужно разрешение «Универсальный доступ»
  (Системные настройки → Конфиденциальность и безопасность → Универсальный доступ).
- На Windows ввод не попадает в окна, запущенные с правами администратора,
  если сам агент запущен без них.
- Телефон и ПК должны быть в одной сети, а гостевая изоляция клиентов на
  роутере — выключена.

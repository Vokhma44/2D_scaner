# Установка и эксплуатация

## Что нужно

- **ПК**: Windows 10/11, macOS 12+ или Linux; Java 17 или новее.
- **Телефон**: Android с Chrome 90+ либо iPhone с iOS 15+ (Safari).
- **Сеть**: телефон и ПК в одной локальной сети, изоляция клиентов на роутере
  выключена.

Для сборки дополнительно нужны JDK 21 и Node.js 20+.

Публичный Windows-пакет уже содержит Java 21. Пользователю отдельно
устанавливать Java, Node.js, Gradle или Git не требуется.

## Запуск готового релиза на Windows

1. Откройте раздел Releases репозитория и скачайте `netscan-windows-<версия>.zip`.
2. Распакуйте ZIP в отдельную папку.
3. Запустите `netscan\netscan.exe`. Агент появится в системном трее Windows и
   продолжит работать в фоне без окна командной строки.
4. При первом запуске разрешите доступ в брандмауэре для частных сетей.
5. Нажмите правой кнопкой на значок РУЗНАК возле часов и выберите
   «Подключить телефон (QR-код)».

Установщик собирается автоматически при публикации тега вида `v1.0.1`.
Исходный код, тесты, встроенная PWA и Java runtime входят в одну воспроизводимую
сборку GitHub Actions.

## Сборка

```bash
git clone https://github.com/Vokhma44/2D_scaner.git && cd 2D_scaner
./gradlew :agent:installDist
```

Готовый агент вместе с мобильным клиентом окажется в
`agent/build/install/netscan/`. Каталог можно целиком скопировать на рабочий ПК —
кроме Java, ничего доустанавливать не нужно.

Пересобрать без Node.js (когда веб-клиент уже собран):

```bash
./gradlew :agent:installDist -PskipWeb=true
```

## Первый запуск

```bash
agent/build/install/netscan/bin/netscan
```

Агент выведет QR-код, адрес, код сопряжения и отпечаток TLS-сертификата.
Наведите камеру телефона на QR-код: браузер откроет сканер, сопряжение
произойдёт автоматически. Предупреждение о сертификате ожидаемо, см.
[SECURITY.md](SECURITY.md).

Проверить ввод, не доставая телефон: откройте `https://localhost:8443/console`,
раздел «Проверка ввода».

## Установка приложения на телефон

- **Android**: меню Chrome → «Установить приложение». Значок появится на
  домашнем экране, приложение запустится в полноэкранном режиме.
- **iOS**: меню «Поделиться» → «На экран Домой».

Установленное приложение помнит сопряжение и подключается к ПК само.

## Постоянная установка в Windows

Артефакт `netscan-windows-<версия>` содержит переносимую JVM и установщик. Полностью
распакуйте архив и запустите `install.cmd`. Файлы устанавливаются без прав
администратора в `%LOCALAPPDATA%\RUZNAK\netscan`, создаются ярлыки в меню Пуск и
автозапуск текущего пользователя. Рабочие данные остаются в
`%USERPROFILE%\.netscan`, поэтому повторный запуск `install.cmd` из новой версии
обновляет программу без потери настроек, сертификата, телефонов и fleet-доступа.

Агент удерживает блокировку `%USERPROFILE%\.netscan\agent.lock`: повторный
запуск больше не создаёт второй сервер и не конфликтует за порты. Для удаления
используйте ярлык «Удалить РУЗНАК netscan» в меню Пуск; пользовательские данные
по умолчанию сохраняются.

## Автозапуск

### Windows

Создайте ярлык на `netscan.bat` в папке автозагрузки
(`Win+R` → `shell:startup`). Чтобы окно консоли не мешало, запускайте через
`Планировщик заданий` с параметром «Выполнять для всех пользователей»;
QR-код в этом случае берите из веб-консоли.

### macOS

`~/Library/LaunchAgents/ru.ruznak.netscan.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>ru.ruznak.netscan</string>
  <key>ProgramArguments</key>
  <array><string>/Applications/netscan/bin/netscan</string></array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
</dict>
</plist>
```

`launchctl load ~/Library/LaunchAgents/ru.ruznak.netscan.plist`

Первый ввод потребует разрешения: Системные настройки → Конфиденциальность и
безопасность → Универсальный доступ → добавить netscan (или терминал, из
которого он запущен).

### Linux (systemd, пользовательская сессия)

`~/.config/systemd/user/netscan.service`:

```ini
[Unit]
Description=netscan — сетевой сканер 2D
After=graphical-session.target

[Service]
ExecStart=%h/netscan/bin/netscan
Restart=on-failure

[Install]
WantedBy=default.target
```

```bash
systemctl --user enable --now netscan
```

Служба должна работать в пользовательской сессии: системному сервису без
доступа к дисплею эмуляция клавиатуры недоступна.

## Настройка под учётную систему

| Задача | Что сделать |
| --- | --- |
| Код должен подтверждаться Enter | `--suffix enter` (по умолчанию) |
| Переход к следующему полю | `--suffix tab` |
| Форма не успевает получить фокус | увеличьте `output.typingLeadMs` |
| Поле «теряет» символы при быстром вводе | увеличьте `--key-delay` до 10–15 мс |
| Учётная система ждёт вместо GS1 свой символ | задайте `output.gs1SeparatorReplacement`; пусто — разделитель уходит как есть |
| Принимать только коды маркировки | `scan.filterRegex` = `^01\d{14}` |
| Принимать только DataMatrix | `scan.allowedFormats` = `["data_matrix"]` |
| Нужны и ввод, и файл для журнала | `--sink keyboard,file --file ~/scans.txt` |
| Данные нужны в своей системе | `--webhook http://localhost:3000/scan` |

Все параметры доступны и в веб-консоли; сетевые применяются после перезапуска.

## Диагностика

| Симптом | Причина и что делать |
| --- | --- |
| Телефон не открывает адрес | Разные сети или изоляция клиентов на роутере. Проверьте `ping` до ПК, откройте порт 8443 в брандмауэре |
| «Браузер запретил камеру» | Страница открыта по HTTP. Открывайте адрес из QR-кода, он ведёт на HTTPS |
| Код распознаётся, но на ПК ничего не появляется | Проверьте `activeSinks` и предупреждения в консоли: в headless-сессии эмуляция клавиатуры недоступна |
| Вместо латиницы вводится кириллица | Активна русская раскладка. Включите `--typing clipboard` |
| Код вводится дважды | Уменьшите паузу после кода на телефоне или увеличьте `scan.duplicateWindowMs` |
| Коды пропадают в дальнем углу склада | Это ожидаемо: они копятся в очереди телефона и уходят при восстановлении связи |
| После смены Wi-Fi телефон не подключается | Адрес ПК изменился. Возьмите новый QR-код: сертификат агент перевыпустит сам |
| Сканы не идут после перезапуска роутера | Откройте приложение на телефоне: оно переподключится само, повторное сопряжение не нужно |

Журнал последних сканов с причиной отказа по каждому — в веб-консоли на ПК и в
разделе «журнал» на телефоне.

## Обновление

Замените каталог установки новой сборкой. Настройки, сопряжения и сертификат
лежат отдельно, в `~/.netscan/`, и переживают обновление. Если протокол
изменится, телефон получит уведомление и обновит страницу.
# Автоматическое обновление Windows

Агент проверяет последний стабильный GitHub Release через минуту после запуска и затем раз в шесть часов.
Обновление принимается только для тега `vX.Y.Z`, ZIP и одноимённого `.sha256` из репозитория
`Vokhma44/2D_scaner`. После проверки SHA-256 отдельный PowerShell-процесс заменяет app-image.
Старая версия удаляется только после 15 секунд стабильной работы новой; при раннем завершении выполняется откат.
Для аварийного отключения задайте пользовательскую переменную среды `NETSCAN_DISABLE_AUTO_UPDATE=1`.

Текущее состояние (`доступно`, `загрузка`, `проверено`, `установка`, `обновлено`,
`ошибка` или `откат`) агент сохраняет в `~/.netscan/update-status.json` и передаёт
во fleet-сервер каждым heartbeat. Причина ошибки отображается в панели при наведении
на статус. После успешного запуска новой версии состояние автоматически меняется на
`обновлено`.
